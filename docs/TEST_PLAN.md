# 테스트 및 검증 기록

확인일 2026-11-11. 합성 테스트만 사용. 실제 학생 적성 분석에 사용하지 않는다.

## 로컬 자동 검증

- `pnpm test`: 설문50+5/영역구성, unknown과 미응답 구분, 선택 서술 공란, 잘못된 응답/키/길이, 미확정 제출 제한, 승인 전 초안→승인 버전 전환 및 과거 응답 보존, 세션복구 보존·전환 후 이전 완료 폐기·명시적 재로딩, Markdown XSS/외부 이미지 차단.
- `pnpm test:db`: PGlite의 실제 PostgreSQL 엔진에서 마이그레이션 실행. auth.uid는 테스트용 설정으로 대체. 사용자2명+관리자1명, RLS격리, 공개학교 seed·최소GRANT·관심FK/타인저장 차단, 사용자 권한 상승 차단, 미승인 실사용 제출 차단, unknown 저장, 필수응답 누락, 멱등 재제출, 제출후 잠금, 사용한 문항버전 수정 차단, 관리자 전용보고서, 게시 스냅샷·비공개 수정·취소·재게시·테스트만 연쇄삭제.
- `pnpm build`: TypeScript 검사와 Vite production 빌드.
- seed.sql은 공개 학교정보/초안문항만 포함. 개인정보/키는 추적대상에서 제외.

PGlite는 Supabase의 호스팅 Auth·JWT·PostgREST를 대체하지 못한다. 이 검증을 운영 서버 검증이라고 표현하지 않는다.

## 브라우저 검증 (개발 미리보기)

- localhost 시작 화면과390×844 모바일 화면 확인.
- 객관식50문항 모두1번→서술형5개 합성문구→검토→미리보기 저장. 실제 제출 아님을 표시.
- 새로고침 후50문항/100% 이어하기. 첫 문항 unknown으로 수정 및 임시 저장.
- 특성화고 필터, 학교 상세 정원·공식 링크 확인.
- 학교와 학과 관심 저장, 선택 이유 기록, 학교2개 비교.
- 여학교 표시 여부 필터, 미로그인 관리자 차단.

## 실제 운영 검증 상태 (2026-11-11)

완료: Vercel HTTPS 접속, synthetic test 로그인, 객관식50개·서술형5개 제출, 실제 DB 저장, 분석 대기, 학교 탐색, 학교/학과 관심과 선택 이유 저장. 초안 복구는 동일한 테스트 계정으로 제출 전에 확인.

운영 API에서 완료: Auth 관리자 식별, 프로필 권한 상승 차단, 사용자별 RLS, 미승인 제출 차단, JSON 내보내기에 해당하는 DB 데이터 검토, 관리자 전용 비공개 초안·게시 스냅샷·취소·재게시, 비관리자 쓰기 차단, 테스트 전용 삭제 후 데이터 0건 검증.

미완료: 크롬 관리자 화면에서 응답 조회/JSON 파일 실제 다운로드/보고서 입력·미리보기·게시를 클릭하는 UI 검증, Supabase Auth Site URL/redirect allowlist 설정, 실제 휴대전화 모바일 데이터 접속. 합성 응답·관심·보고서는 운영 DB에서 삭제 완료.

추가로 운영 HTTP에서 두 사용자 간 조회/쓰기 거부, 닉네임만 로그인 불가, 공개 가입 비활성, 비관리자 RPC거부, 미게시 결과 비공개, 중복 제출 잠금, unknown, 서술공란, 승인 버전 일치를 확인했다. DB중단/오프라인 저장오류 재시도, 실제 모바일 데이터, 학교 링크 정상접속은 아직 확인하지 않았다.

## 관찰된 수정

DB 통합검증에서 PL/pgSQL 변수와 JSON 별칭이 겹쳐 발생한 모호성 오류를 찾아 별칭을 분리했다. 코드리뷰에서 동일세션 로그인 이벤트 초기화, 계정전환 뒤 늦은 저장완료, 초안 로드 전 편집 가능 문제를 발견해 수정했다.

## 승인 문항 v2 검증

단위11개·DB정책 통합검증·빌드 통과. 운영 DB의 v2 승인상태 및55문구 전체를 소스와 대조했다. 기존 테스트 제출1건은 v1·under_review·55개 응답 유지. 테스트를 새 버전으로 이동시키거나 답변을 덮어쓰지 않았다.
