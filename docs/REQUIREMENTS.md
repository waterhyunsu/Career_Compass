# 요구사항 및 현재 상태

## TCREI 실행 계약

| 구분 | 적용 |
|---|---|
| Task | 자기이해, 학교 탐색, 관심 비교, 형의 수동 분석, 결과 열람 |
| Context | 기초 조사 30문항 답변 대기, 학생 자율성, 개인정보 최소화 |
| Reference | 현재 인수인계서, 실제 접근한 공식 자료; 공유 대화 본문 미확보 |
| Evaluate | 기능·보안·모바일 검증과 외부 연동 증거 분리 |
| Iterate | Phase 1 구현을 재사용하며 승인 문항 버전을 새로 등록 |

## 확정 및 구현

- React/Vite/TypeScript/Tailwind, Supabase Auth/PostgreSQL/RLS 구조.
- 이메일·비밀번호 로그인, 닉네임 표시용, 관리자 SQL 지정, 테스트 계정 별도 구분.
- 객관식 20/10/10/5/5 총50개 + 선택 서술5개를 데이터로 관리.
- 전체 진행률·영역 이동·이전다음·답변 검토·임시 저장·이어하기·제출 공통 흐름.
- unknown 별도 값, 선택 서술 공란 허용.
- DB 저장 응답을 받은 후에만 실제 제출 완료 표시.
- draft → submitted → under_review → published, 제출 후 답변 잠금.
- 학교 필터·검색·상세·공식 출처·최대3학교 비교·학교/학과 관심과 학교 선택 이유.
- 관리자 설문 원문·버전·관심 확인, JSON 내보내기, Markdown 초안·미리보기·게시·취소·재게시, 테스트 데이터 삭제.
- 게시본 스냅샷을 초안과 분리하여 새 비공개 수정 노출 방지.
- 미설정 환경 개발 미리보기는 합성 데이터만 로컬 저장하며 DB 제출을 모사하지 않음.

위 항목은 코드 기반 구현 상태다. 호스팅 Supabase와 실제 계정의 전체 시나리오 완료를 의미하지 않는다.

## 보류

- 기초 조사 원문 및 직접 답변 기반 프로필, 최종 문항·해석 기준: 답변과 형의 승인 대기.
- 개인 분석·개인별 학교 적합성: 실제 응답과 별도 수동 검토 이후.
- 학교 전체 정보 검증: 존재·성별·전형·직업학과 정원 중심 일부 확인. 2027 전체 명부 완결성·교육과정·성과·통학 미확인.
- GitHub 원격 push / Supabase 프로젝트·계정 / Vercel HTTPS 배포: 연결 정보 없음.
- 모바일 데이터 외부 접속: 실제 배포 후 사용자 기기로 확인 필요.

## 비기능 기준

미성년자 원문 Git 제외, 비밀키 클라이언트 노출 금지, 모든 데이터 권한 DB 검증, 관리자 초안 비공개, Markdown HTML 미실행, 외부 이미지 차단, 모바일390px 확인, 키보드 포커스와 레이블, 오류 시 성공 표시 금지.
