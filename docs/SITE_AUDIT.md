# 진로 나침반 사이트 검수 기록

검수일: 2026-11-12 (한국시간). 운영 사용자 응답·관심 학교·보고서·권한·설문 버전을 변경하지 않았다. 공개 소스의 표현을 표시 단계에서 정리했으며 `src/data/schools.json`, `src/data/career-pathways.json`, Supabase DB의 원문·출처는 보존했다. 사이트를 운영 데이터에 연결하지 않은 별도 Vite 미리보기로 인터랙션을 재현했다.

## 1. 검수 화면

운영 사이트에서 시작, 일반고·특성화고 비교, 학교 둘러보기, 학과·직무 비교, 설문, 관심, 결과, 잘못된 경로의 접근 가능한 첫 화면을 읽기 전용으로 확인했다. 미리보기에서는 관리자 접근 제한도 확인했다. 설문 제출·관심 저장·보고서 게시·권한 변경·운영 데이터 삭제는 수행하지 않았다. 설문·결과의 상태별 화면과 사용자 격리는 기존 자동 테스트와 독립 PostgreSQL 테스트에서 확인했으며 실제 사용자 보고서·관리자 설정은 열거나 변경하지 않았다.

## 2. 확인한 문제와 조치

1. 학과 상세에서 같은 ‘보장 아님·개설 확인 필요’가 학과마다 반복되고 일반고에는 ‘자료 확인 필요’만 여러 번 노출됐다. 학생 화면을 학교가 소개한 내용과 선택해 볼 질문으로 다시 구성하고 2027 편제표와 자격 응시 조건은 학과별 반복 대신 학교별 안내로 묶었다. 내부 원문은 남겼다.
2. 학교 유형 비교에 충주 평준화와 학교장전형의 차이가 없어, 동지역 4지망·성적군 배정과 중앙탑고·충원고 등의 학교장전형을 구분했다. 바리스타 경험만으로 학과를 결정하지 않아도 된다는 질문, 특성화고가 무조건 쉽지 않다는 설명을 추가했다.
3. 768px에서 주 메뉴가 화면 밖으로 31px 밀리고, 시작 화면의 장식 궤도가 360px과 768px에서 가로 넘침을 만들었다. 태블릿 메뉴를 접고 장식 영역의 가로 넘침을 제한했다. 긴 학교 상세에서는 닫기 버튼을 스크롤 중에도 보이게 했다.
4. 신입 공고 15개 중 3개는 응답 자체가 HTTP 200이더라도 공고 내용이 현재 나타나지 않았다. 학교·직무 페이지의 범위·공고 목록·표본 평균에서 제외했다. 남은 공고의 시작액을 중복 제거 후 재계산해 12건, 연 약 2,830만원을 표시한다. 전국 평균이나 졸업생 임금으로 바꾸지 않았다. 조건(지역·경력·계약·근로시간·상한)과 기준연도는 유지했다.
5. 학교별 관심 활동을 직접 생각해 보는 질문을 넣었다. 특정 학생의 성향·학교 적합성을 판정하거나 학교를 자동 추천하지 않는다.

## 4. 학교·학과 자료 검증

11교(국원·충주·충주대원·충주중산·충주여·충주예성여·중앙탑·충원·충주공업·충주상업·한림디자인)의 명칭·공사립·성별·주소는 `docs/SCHOOLS.md`에 기록된 2026-11-11 NEIS 원문(적재일 2026-04-23)을 사용했다. 충주 4개 남학생 평준화 후보와 2개 여학교는 교육감전형, 중앙탑고·충원고는 학교장전형이다. 한림디자인고는 여학생 모집으로 별도 표시된다. 성별 표시만으로 전체 지원 자격이나 합격 가능성을 판단하지 않는다. [충북교육청 2026 자율형 공립고 운영계획 목록](https://www.cbe.go.kr/dept-25/na/ntt/selectNttList.do?bbsId=2114&mi=16042)에서 충주고·충주예성여고를 확인했고, 일반고 검색 범주에 함께 두면서 학교 유형을 자율형 공립고로 표시했다.

## 6. 직무·급여·출처 검수

[고용노동부 2026 하반기 업종 전망](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=19797)은 기계·전자/디스플레이·금속가공을 전년 동기 대비 유지로 설명한다. 이는 특정 학교 졸업생의 취업 전망과는 다른 산업 전체 통계다. [교육부·한국교육개발원 2026 조사](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=107565&lev=0&m=020402)에서 전국 직업계고 졸업자 진학률 49.2%를 확인했으며 개별 학교의 통계로 사용하지 않는다.

고용24의 [반도체 장비 조립](https://www.work24.go.kr/wk/a/b/1500/empDetailAuthView.do?infoTypeCd=VALIDATION&infoTypeGroup=tb_workinfoworknet&wantedAuthNo=K172112610190057), [산업 자동화 프로그램 신입](https://www.work24.go.kr/wk/a/b/1500/empDetailAuthView.do?infoTypeCd=VALIDATION&infoTypeGroup=tb_workinfoworknet&wantedAuthNo=K141212610220011), [호텔 프런트](https://www.work24.go.kr/wk/a/b/1500/empDetailAuthView.do?infoTypeCd=VALIDATION&infoTypeGroup=tb_workinfoworknet&wantedAuthNo=K180022611020056)는 급여·학력·신입·근무시간을 직접 대조했다. 호텔 공고는 3개월 계약과 교대 조건을 포함한다. 나머지 9개 가용 공고는 원문 응답에서 급여·학력·신입 관련 문자열을 기계 대조했으며 모든 근로조건을 이번에 사람이 재확인한 것은 아니다. 공고는 모집 종료 또는 수정될 수 있다.

K130112609020060, K180522609010016, KJK4002610270001은 해당 시각 원문 본문을 확인할 수 없어 학생 화면과 12건 표본에서 제외했다. 단순 HTTP 200만으로 공고가 있다고 판단하지 않았다. 원본 조사 자료는 보존하고 노출 제외 목록은 `src/lib/careers.ts`에서 관리한다. 학과·직무별 공고가 소수인 점, 세전·2026년·전국 지역 혼합, 상한 미기재, 모집공고의 월액 연환산 및 표본이 전국 평균이 아니라는 점은 화면에서 유지한다. `docs/CAREER_PATHWAYS.md`의 개별 공고는 최초 조사 원문 기록이다.

## 7. 반응형과 기능 검증

브라우저 뷰포트 360·390·430·768·1440px에서 시작·학교 유형·학교 목록·학과 비교의 문서 가로 넘침을 측정했다. 768px 메뉴 및 시작 화면 장식 넘침을 수정해 재측정했다. 360·390·430·768·1440px에서 학교 상세의 모달 너비와 내부 가로 넘침도 확인했다. 390px에서 닫기 버튼이 스크롤 중 화면에 남는 것을 확인했다. 실제 휴대폰 기기·모바일 데이터 네트워크는 미검증이다.

독립 미리보기에서 특성화고 필터, 학교명 검색, 여학생 모집 학교 포함 토글, 학교 상세·학과 펼침, 2개 학교 나란히 비교, 학과 학교 필터·직무 검색, 직무 상세와 복귀, 잘못된 경로 화면을 확인했다. 화면에 별도의 정렬 기능은 없다. 로그인·설문 진행은 미리보기와 자동 테스트로 확인했으며 제출은 하지 않았다. 공식 자료 링크 17건은 읽기 요청으로 응답 여부만 확인했다.

## 9. 미완료·운영 참고

2027학년도 학교별 실제 선택과목 편제표·진학/취업 프로그램 전체·통학 소요시간, 모집요강 최신 정정의 완전 여부, 개별 학교 진학·취업 실적은 확인하지 못했다. 충주상고 일정 충돌은 학교에 직접 확인해야 한다. 고용24 12개 사례의 모든 세부 조건과 모든 2027 공식 문서를 이번 작업에서 전부 다시 열어 대조한 것은 아니다. 자료는 향후 변경·삭제될 수 있어 학과 편제와 채용공고를 주기적으로 갱신한다. 운영 데이터 저장·제출·삭제 전 과정을 이번 검수에서 재실행하지 않았으며 이는 명시적 금지에 따른다.
