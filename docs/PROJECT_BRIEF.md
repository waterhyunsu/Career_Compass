# 프로젝트 개요

프로젝트: 진로 나침반 / Career Compass

중학교 학생이 관심과 경험을 돌아보고, 실제 고등학교 정보를 비교하며 진학 방향을 스스로 설명하도록 돕는 개인용 서비스다. 진로가 미정이어도 괜찮다. 꿈을 강요하지 않고, 성적보다 경험을 먼저 살피며, 추천 순위보다 선택 이유를 중시한다. 형과 AI는 자료 정리와 판단을 보조한다.

자동 적성 판정, 합격 예측, 실시간 AI 분석을 구현하지 않는다. 수동 검토 보고서는 관리자가 별도로 분석·검토한 뒤 게시한다.

2026-11-11 기준 기초 자기이해 조사 30문항을 카카오톡으로 보냈으며 답변 대기 중이다. 정식 설문을 대체하지 않는다. Phase 1은 계속 진행하며 최종 50+5 문구, 해석 기준, 개인별 학교 검토는 답변 수령과 사용자 승인 이후 확정한다.

성공은 학생이 관심·비선호의 이유, 일반고·특성화고의 차이, 관심 학교·학과와 선택 이유, 아직 확인할 경험을 설명할 수 있는 상태다. 학교 한 곳을 자동 선정하는 것이 아니다.

개인 신상과 초기 전달 정보는 Git에서 제외한 docs/USER_PROFILE.md에 보관한다. 공개 문서와 소스에 성적·학교·생년·거주 동 등의 개인 자료를 넣지 않는다. 통학 기준은 학교 조사에 필요한 동 수준으로만 사용하며 정확한 주소는 수집하지 않는다.
