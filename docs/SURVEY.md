# 설문 문항 · 검토용 초안

버전: draft-2026-11-11-v1

기초 조사 답변을 수령했고, 수정 제안과 해석 초안을 비공개 검토 경로에 보관했다. 아래는 현재 배포 중인 기존 초안이다. 승인 후 새 버전을 등록하며 기존 응답 버전은 보존한다. 기존 공유 대화의 문항을 읽지 못해 새로 작성한 초안이며 복원이 아니다. 형의 검토·승인 전 실제 학생 최종 제출은 차단된다. 문항 해석 기준과 개인화 보고서는 미확정이다.

## 응답 기준

1 전혀 아니다 / 2 아닌 편이다 / 3 보통이다 / 4 그런 편이다 / 5 매우 그렇다 / unknown 모르겠다·경험이 없다. unknown은 점수 계산에서 제외하며 0점으로 바꾸지 않는다. 점수 합계로 적성·학교를 판정하지 않는다. 객관식은 최종 제출 전 모두 응답하되 unknown을 사용할 수 있다. 서술형은 선택이며 각각 최대 5000자.

## 서술형 5문항 (선택)

1. 지금까지 가장 재미있게 했던 활동과 그 이유를 적어 줄래?
2. 어렵거나 싫어서 그만둔 일이 있다면 무엇이 어려웠을까?
3. 누가 시키지 않아도 스스로 찾아서 해본 일이 있을까?
4. 충주상고 설명회에서 마음에 들었던 점과 아쉬웠던 점은? (참여하지 않았다면 건너뛰어도 돼.)
5. 고등학교를 선택할 때 가장 걱정되는 것은 무엇일까?

## 추가 자유 질문 제안 (미반영)

다른 사람들의 기대나 성적, 취업 걱정을 잠깐 내려놓는다면 고등학교에서 가장 해보고 싶은 것은 무엇인가?

정식 5문항 외 추가 질문은 선택적 제안으로 남기며 55개 문항 데이터에는 넣지 않았다. 사전 조사 29번과 중복하므로 Phase 2에서 필요성을 검토한다.

## Phase 2 검토 절차

직접 응답과 형의 전달 정보를 분리하고, 30문항과의 중복·빈틈·유도 표현·영역 편향을 검토한다. 특히 t01~t05는 사전 조사와 겹치므로 반복 필요성을 평가한다. 관심 분야를 이유로 특정 직업을 추천·배제하지 않는다. 수정안과 근거를 보고하고 승인 후 새 버전을 생성한다. 과거 응답이 있는 버전은 수정하지 않는다.
