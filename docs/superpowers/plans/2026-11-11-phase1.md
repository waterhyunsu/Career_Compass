# Phase 1 Implementation Plan

> 실행: superpowers:executing-plans. 인수인계서의 즉시 실행 지시에 따라 현재 폴더에서 구현한다.

**Goal:** 최종 문항 확정 전에도 사용할 수 있는 공통 기능과 안전한 데이터 기반 구축.
**Architecture:** React SPA + Supabase의 인증·RLS·트랜잭션 RPC. 미설정 환경 미리보기 분리.
**Tech Stack:** React, Vite, TypeScript, Tailwind, Supabase, Vitest.
**Spec:** ../specs/2026-11-11-career-compass-design.md

## Global Constraints
실시간 AI 없음. 개인정보 Git 제외. 미확인 학교 정보 표시. 문항 확정 대기.
