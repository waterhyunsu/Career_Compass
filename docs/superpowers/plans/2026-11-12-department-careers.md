# 두 직업계고 학과별 직무·시장·초봉 자료 추가

사용자 요청: 충주공업고4학과, 충주상업고5학과의 공식 졸업후 진로 자료를 우선 확인하고 실제 직무와 시장 흐름, 고졸 신입 초봉 참고 추정치를 학교 상세에 제공한다.

## 정보 설계

- src/data/career-pathways.json: 공개 출처 레지스트리, 확인일·자료시점,9개 학과별 직무/진입조건/추가학습 경로/시장기회·주의/급여공고근거. 학교 취업실적과 일반 직업정보를 구분.
- src/components/DepartmentCareer.tsx: 학과마다 접고 펼치는 '졸업 후 직무·초봉 보기'. 현재 자료와 추정임을 본문 옆에 명시하고 공고의 학력/신입 여부/지역/시간·수당조건과 원본 출처를 제공.
- SchoolsPage와 CSS: 기존 학과 교육내용·관심 기능 뒤에 정보 연결. 일반고의 대학진학만을 유일한 경로로 표현하지 않음.
- generate-seed.mjs: 학과 details에 career 자료 포함, 별도 careers 갱신 SQL 생성. supabase/migrations/202611120004_department_careers.sql로9개 학과 갱신. 개인 응답·설문·보고서 변경 없음.
- docs/CAREER_PATHWAYS.md: 출처/해석/급여 산정방법 및 검증 한계 기록.

## 순서와 완료 조건

1. 공식 학교 자료/정부시장 전망/고졸 또는 학력무관 신입 공고 연구. 직무와 학력·자격이 다른 고경력/전문직 경로 구분.
2.9개 학과 공개 데이터 작성. 연봉은 세전 만원/년, 월공고는12배 환산, 전국소수표본. 상한 정보 없으면 숫자를 만들지 않고 자료부족 표시.2026현재 자료이며 실제 졸업시점 예측 아님.
3. 데이터 계약·학교ID/출처/급여환산·미지원 학과·UI 표시 회귀 테스트를 먼저 추가하고 구현.
4. 단위·정책·빌드 검증, DB9개 학과 details 반영/소스 일치, 기존 응답 보존 확인.
5. Git 커밋/푸시, Vercel 배포, 실제 두 학교 상세 접힘패널 확인, 화면 증거와 보고 제공.

개인 적성 점수·학교 순위·취업보장·졸업생 평균연봉을 만들지 않는다. 자동외부AI API를 추가하지 않는다.
